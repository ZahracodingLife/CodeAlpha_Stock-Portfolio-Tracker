# Stock Portfolio Tracker 

A simple Python-based stock portfolio tracker that allows users to enter stock names and quantities, calculate individual investment values, and calculate the total portfolio investment.

### Features

* Uses a dictionary to store predefined stock prices
* Allows users to add multiple stocks
* Calculates investment value for each stock
* Calculates total portfolio investment
* Handles invalid stock names
* Displays a portfolio summary
* Saves the portfolio information to a `.txt` file

### Concepts Practiced

* Dictionaries
* Lists
* `while` and `for` loops
* `if` statements
* User input and output
* Basic arithmetic
* F-strings
* File handling with `open()` and `write()`

### How It Works

The user enters a stock symbol and the quantity they own. The program looks up the stock price from a predefined dictionary, calculates the investment value, and adds it to the total portfolio value.

Type `DONE` when finished to display the portfolio and save the results to `portfolio.txt`.
